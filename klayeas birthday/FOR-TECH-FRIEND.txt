2. VERCEL:
   - Go to vercel.com

   - Drop file or connect GitHub repo
   - Get live URL

3. GITHUB PAGES (FREE):

   - Upload HTML file as "index.html"
   - Enable GitHub Pages in settings
   - Get yourname.github.io/reponame URL

4. ANY HOSTING:
   - Upload the HTML file to any web hosting
   - Rename to "index.html" if needed
   - It's just a single HTML file - works anywhere

🔧 TECHNICAL NOTES:
- Uses localStorage for persistence (data stays on user's browser)
- No backend needed - it's completely client-side
- Responsive design works on all devices
- Uses Tailwind CSS via CDN
- Vanilla JavaScript - no dependencies

⚠️ IMPORTANT:
- Each user's bookings are saved locally on their device
- For true shared state, you'd need to add a backend
- But for a birthday party, local storage is probably fine
- People can coordinate via Discord/chat anyway
