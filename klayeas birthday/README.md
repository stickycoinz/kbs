# 🎂 Klayea's Birthday Stream Collab List

A beautiful, interactive web application for coordinating streaming slots during Klayea's birthday celebration weekend (September 19-21, 2024).

## Features

- **Interactive Time Slots**: Click to select and book 2-hour streaming slots
- **Multi-timezone Support**: Shows both Eastern Time (EST) and British Summer Time (BST)
- **Real-time Booking**: Instantly book and manage streaming slots
- **Notes Section**: Add special requests or availability preferences
- **Mobile Responsive**: Works perfectly on all devices
- **Accessible**: Full keyboard navigation and screen reader support

## Quick Start

### Deploy to Vercel (Recommended)

1. Click the deploy button: [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yourusername/klayeas-birthday-stream)

2. Or manually:
   - Push this code to a GitHub repository
   - Connect your GitHub to Vercel
   - Deploy the repository

### Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Streaming Schedule

- **Friday, September 19th**: 5 PM - 11 PM Eastern (10 PM - 4 AM BST)
- **Saturday, September 20th**: 10 AM - 10 PM Eastern (3 PM - 3 AM BST)  
- **Sunday, September 21st**: 12 PM - 6 PM Eastern (5 PM - 11 PM BST)

Each slot is 2 hours long and can be booked by entering your streaming name.

## How to Use

1. Browse available time slots for each day
2. Click on any available slot to select it
3. Enter your streaming name or handle
4. Click "Book Slot" to reserve your time
5. Use the notes section for special requests or flexible availability
