# Turntable layers

These images are 1025×821 and stack in this order.

| File | What it is | Moves? |
|---|---|---|
| `01-base.png` | The turntable, with a black record underneath | No |
| `02-vinyl.png` | The white record and its blank label | Spins |
| `03-tonearm.png` | The tonearm | No |

Spin the white record around pixel (495, 399), which is `transform-origin: 48.29% 48.64%`. One full turn every 1.8 seconds matches 33⅓ rpm.

Open `demo.html` from this folder to see it spin. There is no grain layer.
